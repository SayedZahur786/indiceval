INDICEVAL / RESEARCH PREVIEW

Privacy

Effective 19 November 2026. IndicEval is a static research website maintained through the project repository.

Website use

The site has no accounts, sign-in, payment flow, or database of uploaded reports. The report inspector reads your selected JSON file locally in browser memory. It does not upload the file. Search and filters are local and are not persisted.

Analytics

Vercel Web Analytics is wired for aggregate website traffic measurement. The client does not intentionally send task searches, report content, API keys or custom events. It skips loading analytics when your browser sends Do Not Track. Blocking analytics does not prevent use of the site. Vercel hosts the site and processes network requests and operational logs under its own policies. See Vercel's analytics privacy documentation.

External services

Fonts are served by Google Fonts, which receives browser requests. GitHub and linked research sources have their own privacy practices. When you submit an issue or pull request, your GitHub identity and content may become public.

Local evaluation

The Python runner sends benchmark prompts to the endpoint you configure. That provider may process or retain them under its policies. API keys are read from an environment variable and are not written into run artifacts. Raw model responses and usage are stored locally in the output directory; review them before sharing. Never submit credentials, private prompts or personal data.

Questions and removal requests

Open a project issue for public, non-sensitive questions. Do not include sensitive information in a public issue. Repository owners can review data correction/removal requests; third-party caches or forks are outside the project's control.
