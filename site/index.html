FROM ENDPOINT TO EVIDENCE

Your model.
A reproducible result.

Run locally with Python and uv. Bring an OpenAI-compatible endpoint; your API key stays on your machine.

  1. Inspect the dataReview the sources and frozen dataset hash.
  2. Run two repetitionsSave every response, error, token count and timing.
  3. Share the evidenceValidate the bundle and open a submission.
TERMINAL
git clone https://github.com/SayedZahur786/indiceval.git
cd indiceval
uv sync --frozen
docker pull python:3.12-slim
uv run indiceval validate-data
Then configure INDICEVAL_API_KEY in your shell and run:
uv run indiceval run \
  --base-url "$MODEL_BASE_URL" \
  --model "$MODEL_ID" \
  --repeats 2 --samples 5 --k 1 5 \
  --temperature 0.7 \
  --output runs/my-model

Set MODEL_BASE_URL and MODEL_ID to your actual endpoint and model. Prices are optional; omitted prices produce unknown cost.
