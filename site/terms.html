Terms of use

Effective 19 November 2026. IndicEval is an experimental, openly inspectable research tool. It is provided as-is without a guarantee of accuracy, availability, security or fitness for a particular use.

Research use

Scores describe performance on a small, public dataset under recorded conditions. They do not establish general intelligence, safety, reliability, cultural competence, or suitability for a consequential deployment. Do not represent fixture diagnostics as model results.

Code and dataset rights

Project code is MIT-licensed. Dataset records retain their individual upstream licences; the repository's code licence does not replace them. XQuAD-IN derivatives retain CC BY-SA 4.0. Consult the source and licence ledger before redistribution. Attribution and licence notices must be preserved.

Contributions

Submit only content and run artifacts you are authorized to publish. Disclose benchmark exposure and evaluation settings. Do not include secrets or personal data. Submitting does not guarantee inclusion in the leaderboard. Maintainers may reject, correct or remove misleading, incomplete or unverifiable results. Corrections should be versioned and linked to their evidence.

Local code execution

The runner requires Docker for generated code. You control the endpoint, API charges and execution environment. Do not execute untrusted code directly on your host or grant the evaluation containers extra privileges. The public site does not provide hosted model execution.
